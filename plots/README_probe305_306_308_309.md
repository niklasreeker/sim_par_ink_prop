# Gleiche sechs Diagramme für Probe 305, 306, 308 und 309

Aus dem Repository-Hauptordner:

```bash
python -m pip install numpy pandas scipy matplotlib tzdata
python plots/plot_probe305_306_308_309.py --probe all --no-show
```

Nur einen neuen Versuch auswerten:

```bash
python plots/plot_probe305_306_308_309.py --probe 308
python plots/plot_probe305_306_308_309.py --probe 309
```

Der bisherige Einstieg `python plots/plot_probe305_306` funktioniert ebenfalls.
`--probe all` umfasst jetzt alle vier Versuche. Ergebnisse liegen standardmäßig
in `plots/results_Probe305`, `plots/results_Probe306`, `plots/results_Probe308`
und `plots/results_Probe309`. Alle bisherigen Optionen bleiben verfügbar.

## Diagramme pro Versuch

1. Kumulativer Tankmassenverlust, roh und um gewogene Proben bereinigt.
2. Dichte und Schallgeschwindigkeit mit Fenster-Standardabweichungen.
3. MA160-Festkörpergehalt an den tatsächlichen Probennahmezeitpunkten.
4. Zusammensetzung aus Dichte/Schall, Rezepturanker am ersten Sensorfenster;
   physikalisches und hybrides Modell mit separatem konstantem Offset.
5. Dichte und Schallgeschwindigkeit auf die mittlere Fenstertemperatur korrigiert.
6. Zusammensetzung aus dem Kalibrierfeld ohne zusätzlichen Sensoroffset.

`--no-field` erstellt die ersten fünf Diagramme mit dem physikalischen Modell.
PNG ist Standard; `--formats png pdf svg` speichert alle drei Formate.

## Übernommene Auswertungsentscheidungen

- Rezepturen entsprechen den dokumentierten Einwaagen. 309 enthält weniger
  SL120; das MG/Pigment-Verhältnis wird für jeden Versuch neu bestimmt.
- 305/306 behalten ihre bisherigen Sensorpunkte, Rückrechnungen und das
  bisherige IDW-Kalibrierfeld als Standard.
- 308/309 verwenden standardmäßig das Gauß-Kalibrierfeld aus Probe 9/10/11,
  mit gespeicherter Kalibrierstärke 0,70 und Bandbreite 0,30.
- Für einen Modellvergleich mit identischem Feld lässt sich bei jedem Versuch
  dasselbe `--calibration-field PFAD` angeben.
- Alle verwendeten Messwerte sind eingebettet. Mit `--csv PFAD` können die
  Fensterwerte aus der Messdatei neu berechnet werden. Für 308/309 gelten:
  `SensOK=1`, `C_M>=1500`, `Rho_S<0.15`, `C_S<1.5`, `C_Sp<5`.
  Dichte, Schall und Temperatur stammen immer aus denselben Zeilen.
- 308: MA160 aus Eimer nur 2,08 %; um 13:13 nur 2,12/2,18 %.
  Andere MA160-Werte bleiben unverändert, ohne weitere Ausreißerentfernung.
- 309: Eimer-MA160 ausgeschlossen. Sensor S0 ist das bereits verwendete
  luftarme Fenster 11:54–11:59; S3/S4 nach Pumpenänderungen sind als
  diagnostische Fits gekennzeichnet, nicht als bestätigter Verdunstungspfad.
- Sensor-, MA160- und Tankwerte sind bei 308/309 getrennte Zeitreihen.
  Es wird keine künstliche zeitgleiche Zuordnung erzeugt. Deshalb enthält
  `festkoerpervergleich.csv` dort keine MA160-Differenzen; die Messwerte stehen
  separat in `festkoerper_messungen.csv`.
- Tankverlust beginnt direkt nach erster Tankprobe; deren Masse wird nicht
  erneut abgezogen. Raten: 308 500,68 g/h; 309 497,14 g/h. Bei identischen
  Minuten vor/nach Entnahme bleibt die Reständerung sichtbar; die einzelne
  Intervallrate ist mangels Zeitauflösung undefiniert. Es werden keine Sekunden
  erfunden. Der bereinigte Tankverlust kann Inventaränderungen enthalten und
  ist keine unabhängig gesicherte reine Verdunstungsrate.
- Der erste Sensorwert wird im verankerten Modell auf die Rezeptur gesetzt;
  dies ist eine Modellannahme trotz möglicher vorheriger Verdunstung.
